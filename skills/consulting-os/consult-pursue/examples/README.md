# Examples — showcase prospects

Showcases of the cold-start single-folder layout. Each subfolder is a frozen snapshot of what `/cos-pursue {client} for {topic}` produced — the user's real runtime folder lives at `prospects/{slug}/` in their working directory, not in this repo.

## Cold-start (most common shortcut)

```text
/cos-pursue {client} for {topic}
```

**How-to:** [../COLD-START.md](../COLD-START.md)

**Showcases:** [`ho-brothers/`](ho-brothers/) · [`vodafone-portugal/`](vodafone-portugal/)

## Full pipeline (brief on hand)

`/cos-plan` → `Input/` → `/cos-research` … `/cos-ship` → `/cos-pursue`

Uses `Output/{Client}-Engagement/` for stage artifacts.

## Resume

```text
/cos-resume prospects/{slug}
```
