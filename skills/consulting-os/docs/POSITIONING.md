# Consulting OS — Positioning

## What this is

Human-in-the-loop copilot for **solo-founder consulting pursuits**: research → frame → design → architect → build → review → ship → pursue. Not an autonomous proposal generator.

## Principles

| Principle | Implementation |
|-----------|----------------|
| **Assistive, not deceptive** | Integrity gate verifies quotes (`timeln-quickly`) and proof (`timeln-shipped`) |
| **Human at every gate** | Frame approval, option pick, diagram sign-off, ship/no-ship |
| **Failure modes visible** | Lint, integrity report, red team, `timeln-warned` scars |
| **Compounding memory** | Six Timeln skills at every stage — no duplicate research skill |
| **MECE skills** | One owner per task; pipeline orchestrates only |

## What it is not

- Not a replacement for legal SOW review
- Not autonomous client outreach without checkpoint
- Not a second Timeln installation — uses existing `timeln-*` skills only
