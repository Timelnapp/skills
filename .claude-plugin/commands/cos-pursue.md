# /cos-pursue

**Quick guide:** [consult-pursue COLD-START.md](../../skills/consulting-os/consult-pursue/COLD-START.md)

## One command

```text
/cos-pursue {client} for {topic}
```

Creates `prospects/{slug}/` with research, synthesized pack, email, and call script.

## Modes

| You have | What happens |
|----------|----------------|
| Client + topic only | **Cold-start** — full folder from public research |
| Pack already in `prospects/{slug}/` | **Standard** — email + call script only |

## Checkpoint

After sending outreach → set `checkpoints.sent_to_client` in `engagement-passport.yaml`.
